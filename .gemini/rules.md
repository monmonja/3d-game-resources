# README & Resource Management Rule

BEFORE modifying `README.md`:

1. **Read `README.md` first**: Always view and inspect existing entries in `README.md` before making edits.
2. **Only External Resource Links**: Only list external resource repositories provided by the user (do not list this repo `monmonja/3d-game-resources` as a resource entry).
3. **Do Not Touch Previous Entries**: Never remove, modify, or rewrite previously added external repository entries.
4. **Append-Only Behavior**: When the user provides a new external GitHub link, inspect it and append it at the bottom of `README.md`.
5. **No Icons / Emojis**: Maintain a clean Markdown structure with headings and bullet points, without emojis or icons.
